# Spielbare Versionen
Jeder Ordner hier ist ein kompletter, spielbarer Stand: Doppelklick auf `Autorennen.html` (oder `Autorennen starten.command`) im jeweiligen Ordner.
Der Ordner Spiele/Autorennen ist immer die neueste Version. Pakete liegen in _pakete/.
| Ordner | Stand |
|---|---|
| v1_2026-10-10_grundspiel | 3 Strecken, 8 Autos, Menü, KI, Split-Screen, Ton |
| v2_2026-10-11_modelle_fahrer | Autos v2, kein Zittern, Fahrerwahl, Titel |
| v3_2026-10-11_tempo_tunnel_fantasie | 220–270 km/h, 7 Stärken, Tunnel/Brücken/Hindernisse, Fantasie mit Loopings |
| v4_2026-10-11_welten_wetter_schaden | Welten, Wetter/Jahreszeit/Wind, Schaden, Schanzen, Turbo/Schild, 10 Gegner |
| v5_2026-10-11_fahrbarkeit_anlauf_zaun | Tempo-Klasse Normal/Schnell, direktere Lenkung, Anlauf, Zaun dicht, Kleber |
| v6_2026-10-11_dino_polizei_formel | Dino-Strecke, Polizei, Formel-Renner |
| v7_2026-10-11_kollisionen_reifen_sterne | Kollisionen ohne Verschmelzung, Rempeln sanft/echt, Abseits/Zaun/Pflanzen, Reifen, Multivan bronze, Welt Alles, Start-Boost, Sterne (Runde 6 W1) |
